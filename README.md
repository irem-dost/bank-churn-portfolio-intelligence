# Bank Churn & Portfolio Intelligence Dashboard

## 🎯 Project Overview
This project delivers an end-to-end data analytics solution designed for executive board-level review. It focuses on identifying customer churn factors, segmenting asset and overdraft balances, and discovering critical insights into user transaction behaviors across digital banking channels.

The project seamlessly integrates data engineering, structured database modeling, and professional presentation across a 3-page interactive Power BI dashboard.

## 📊 Dashboard Structure
The interactive report is systematically divided into three strategic pillars:
1. **Bank Churn & Portfolio Intelligence:** Tracks overall churn rates, potential churn volume, and analyzes demographic distributions (gender, age group) affecting customer retention.
2. **Asset & Transaction Insights:** Deeply investigates financial status by segmenting average account balances, total overdraft exposure, and total transaction volumes across commercial categories (Salary, Investments, Travel, etc.).
3. **Digital & Activity Insights:** Measures user engagement through digital channels, tracks monthly volume trends, and highlights transaction frequencies to show how customers naturally interact with banking services.

## 🛠️ Tech Stack & Methodology
- **Data Architecture:** Reconciled customer profiles and massive transactional datasets (30,000+ rows).
- **Data Engineering & Generation (Python / Jupyter):** Handled automated raw data structures, missing records handling, and schema validation.
- **Database Modeling (SQL):** Structured optimized querying pipelines for relational database components.
- **Data Modeling & DAX (Power BI):** Developed relations and wrote custom measures to avoid data redundancy.
- **Visual Design:** Structured using corporate color palettes, custom UI containers, and aligned KPI blocks optimized for C-level presentation.
